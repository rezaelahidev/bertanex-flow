پیامک و ایمیل وردپرس و ووکامرس را خودکار می‌فرستد و هر فلو را خودتان ویرایش می‌کنید.

== Description ==

برتانکس فلو برای فروشگاه و سایت وردپرسی است.

* بعد از ثبت‌نام، سفارش، دیدگاه و تغییر رمز، ایمیل یا پیامک بفرستید.
* فلوهای آماده وردپرس و ووکامرس را از پیشخوان ویرایش کنید.
* پیامک را با ملی‌پیامک بفرستید.
* قالب ایمیل را خودتان انتخاب کنید.
* پیشخوان در زبان فارسی راست‌چین است.

== Installation ==

1. پوشه `bertanex-flow` را در `wp-content/plugins` بگذارید، یا فایل فشرده را از پیشخوان بارگذاری کنید.
2. افزونه را فعال کنید.
3. از منوی «فلو» راه‌اندازی را تمام کنید.

وردپرس ۶.۵ یا جدیدتر و PHP ۸.۱ تا ۸.۴ لازم است. برای فلوهای فروشگاه، ووکامرس را هم فعال کنید.

== Frequently Asked Questions ==

= به‌روزرسانی چطور انجام می‌شود؟ =

اگر به‌روزرسان ژاکت را نصب کرده‌اید، از صفحه افزونه‌ها به‌روزرسانی کنید. در غیر این صورت فایل جدید را جایگزین پوشه افزونه کنید و یک بار پیشخوان را باز کنید. تنظیم‌های ذخیره‌شده پاک نمی‌شوند.

= لایسنس جدا لازم است؟ =

خیر. افزونه بعد از فعال‌سازی بدون ثبت لایسنس کار می‌کند.
